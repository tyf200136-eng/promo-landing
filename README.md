# صفحة برومو — دليل سريع

افتح `index.html` بالمتصفح مباشرة. ما يحتاج سيرفر ولا جافاسكربت.

## الملفات
- `index.html` الصفحة الرئيسية
- `terms.html` الشروط والأحكام
- `privacy.html` سياسة الخصوصية
- `css/style.css` كل التنسيقات (الألوان في أول الملف تحت `:root`)
- `assets/` الصور والأيقونات وخط Tajawal (محلي، يشتغل بدون إنترنت)

## صور لازم تستبدلها من فيقما (نفس الاسم والمكان)
طريقة التصدير: حدد الطبقة في فيقما ← Export ← PNG بحجم 2x.

| الملف | الطبقة في فيقما | ملاحظة |
|---|---|---|
| `assets/hero-mockup.png` | "موك اب برومو ٢ 1" داخل HERO | حالياً إطار فاضي مؤقت |
| `assets/cta-phones.jpg` | "promoo (1) 1" داخل CTA (صدّرها PNG واسمها cta-phones.png وعدّل الامتداد في index.html) | حالياً قص من لقطة شاشة |
| `assets/partners/*.png` | شعارات الشركاء الثمانية | حالياً بدقة منخفضة |

## أماكن تحتاج تعدلها لاحقاً
ابحث عن `href="#"` في `index.html`:
- زر "ابدأ الآن" و "تسجيل الدخول" (الناف بار)
- زر "ابدأ التسوق الآن"
- زر "انضم كشريك"
- أزرار App Store و Google Play

وابحث عن `info@example.com` و `+966500000000` في `index.html` و `privacy.html` وحط الإيميل والرقم الحقيقيين.
